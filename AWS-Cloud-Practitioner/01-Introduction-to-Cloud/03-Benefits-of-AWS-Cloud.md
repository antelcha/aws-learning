# Benefits of AWS Cloud

**Course:** AWS Cloud Practitioner — Introduction to Cloud  
**Progress:** Third video completed

## Benefits Mentioned

| Benefit | Practical meaning |
| --- | --- |
| 1. Pay as you go | Replace large upfront investments with usage-based spending. Pricing details vary by service. |
| 2. Benefit from massive economies of scale | AWS aggregates demand across many customers, enabling lower variable costs than many organizations could achieve independently. |
| 3. Stop guessing capacity | Add or remove resources as demand changes instead of committing to uncertain capacity in advance. |
| 4. Increase speed and agility | Provision resources in minutes, experiment faster, and deprovision what is no longer needed. |
| 5. Stop spending money running and maintaining data centers | Avoid much of the work and expense associated with owning and operating physical infrastructure. |
| 6. Go global in minutes | Deploy applications closer to users through AWS's global infrastructure without building physical facilities. |

## Physical Infrastructure Reminder

Do not gloss over the physical infrastructure and operational costs being compared with cloud computing:

- Hardware
- Staff
- CPU capacity
- Storage
- Infrastructure maintenance

## Provisioning and Deprovisioning

- **Provisioning:** Creating, configuring, and preparing a resource for use.
- **Deprovisioning:** Removing a resource or releasing its allocated capacity when it is no longer needed.

For example, creating and starting an Amazon EC2 instance is provisioning. Terminating it is deprovisioning. Depending on the AWS service, deprovisioning can delete data; it does not always mean merely stopping a resource.

Fast provisioning and deprovisioning contribute to the cloud benefit of increased speed and agility.
