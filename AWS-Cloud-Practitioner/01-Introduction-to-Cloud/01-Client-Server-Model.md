# Client–Server Model

**Course:** AWS Cloud Practitioner — Introduction to Cloud  
**Progress:** First video completed

## Mustafa's Explanation

The server is the barista, the request is the coffee order, and the response is the coffee.

## Clarification

In the coffee shop analogy:

| Client–server concept | Coffee shop role |
| --- | --- |
| Client | Customer |
| Server | Barista |
| Request | Coffee order |
| Response | Prepared coffee or an error, such as the drink being unavailable |

The client initiates a request. The server receives and processes it, then returns a response. A response does not always mean success.
